# Contributing to Bank Market Investigative Research

Contributions are welcome! Please follow these principles:

1. **Evidence First:** Do not assert assertions as facts. Maintain the five-tier evidence standard.
2. **Progressive Disclosure:** Keep `SKILL.md` concise (< 850 words). Move deep domain mechanics into `references/`.
3. **Auditability:** Any quantitative model must remain deterministic with explicit assumptions.
4. **Validation:** Run `python scripts/validate_skill.py` and `python -m unittest discover -s tests` before submitting pull requests.
