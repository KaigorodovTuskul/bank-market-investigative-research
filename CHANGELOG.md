# Changelog

All notable changes to `bank-market-investigative-research` will be documented in this file.

## [1.0.0] - 2026-10-30

### Added
- Standardized open-spec Agent Skill structure in `skills/bank-market-investigative-research/`.
- Five-tier evidence verification model: Established, Reported, Derived, Hypothesis, Unresolved.
- Separation of wholesale bank-to-bank funding from deposit brokerage and client onboarding.
- Specialized topic references: `source-evidence.md`, `bank-market-data.md`, `funding-economics.md`, `legal-and-compliance.md`, `management-report.md`, `sources-and-search.md`.
- Deterministic Python cost-of-funds calculator `scripts/funding_economics.py` with synthetic test cases.
- Zero-dependency multi-agent installer script `scripts/install.py`.
- Automated spec compliance validator `scripts/validate_skill.py` and unit tests.
